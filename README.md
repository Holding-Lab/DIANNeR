# DIANNeR

Code supporting the **DIANNeR** manuscript  
*“Cross-tissue analysis of the glucocorticoid receptor interactome by label-free DIA-NN-enabled RIME (DIANNeR) reveals conserved transcriptional roles and tissue-specific functional enrichment”*.

This repository contains the R code used for analysis and figure generation in the manuscript.

## Figures

- **Figures 1–7** are contained in `DIANNeR-figures.svg`
- **Figures 8–9** are provided as individual SVG files in their respective subfolders

## Analysis code

All analysis and figure-generation code is written in **R**.

Supporting scripts are organised into named subfolders corresponding to analyses described in the manuscript. Scripts should run independantly. 


## Notes

- Proteomics data were processed using DIA-NN, with downstream analysis by FragPipe and visualisation performed in R.
- This repository is intended to support transparency and reproducibility of the published results rather than to function as a general-purpose software package.

## Citation

If you use this code, please cite the DIANNeR manuscript.
